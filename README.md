Gender Classification Project

Классификация пола по физическим параметрам с использованием машинного обучения.
📋 Описание

Проект представляет собой модель машинного обучения для бинарной классификации пола (мужской/женский) на основе антропометрических данных. Модель обучается на датасете с физическими параметрами людей и предсказывает пол по новым данным.
✨ Возможности
🔍 Предобработка и анализ данных
📊 Визуализация распределения признаков
🎯 Обучение модели классификации
💾 Сохранение модели в файл (.pkl)
🔮 Предсказание на новых данных
